# Site DNA — Phase 12: Report Specification & Data Schema

**Organization:** ASAAS AI — أساس للذكاء الاصطناعي  
**Product:** Site DNA — بصمة الموقع  
**Phase:** 12 — Final Reporting Specification  

---

## 1. Supported Document Modes

Site DNA provides three dedicated report depth modes:

| Mode | Target Audience | Scope | Target Pages |
| :--- | :--- | :--- | :--- |
| **`comprehensive`** | CTO, VP Engineering, Lead Architects | Full multi-phase technical audit across all 12 domains, complete evidence index, all unified findings, full 4-wave roadmap, provenance manifest | 5–12 Pages |
| **`executive`** | CEO, Board Members, Managing Directors | High-level strategic briefing, overall health index (0–100), critical risk matrix, wave investment summary, explicit limitation disclosures | 3–5 Pages |
| **`agent`** | Domain Specialist (SEO, Security, A11y) | Deep dive into a single analysis stage (e.g. `accessibility`), detailed criterion-level checks, full code snippets, and verification procedures | 2–4 Pages |

---

## 2. Report Sections & Order (A4 Document Layout)

1. **Cover Page & Header:**
   - Official ASAAS AI logo (`logo-dark.png`) embedded as data URI.
   - Document Title: `Site DNA — تقرير بصمة الموقع التنفيذي والمؤسسي`.
   - Run Metadata: Target URL, Analysis Run ID, Report ID, Generation Date (UTC), Document Mode, Language.
   - Overall Strategic Health Index Scorecard (`/100`).

2. **Executive Narrative & Core Findings:**
   - Executive briefing synthesized in Arabic RTL (with English parallel summary).
   - Key conclusions and strategic takeaways.
   - Transparent AI Quota / Execution Disclosure notice.

3. **Multi-Agent Health & Domain Scorecard:**
   - Performance across Visual Identity, UX/UI, Content Marketing, Technical SEO, Competitor Intelligence, Security & Privacy, Accessibility, and Strategic Intelligence.
   - Available vs. blocked stages.

4. **Critical Issues & Vulnerability Highlights:**
   - Table of P0 / Critical severity issues with domain, title, and traceable evidence reference.

5. **Unified Implementation Roadmap (4 Waves):**
   - Wave 1: Immediate Critical Remediation (Weeks 1–2).
   - Wave 2: Core Optimization & Performance (Weeks 3–6).
   - Wave 3: Advanced Accessibility & Trust (Weeks 7–10).
   - Wave 4: Continuous Monitoring & Governance (Weeks 11+).

6. **Evidence Catalog & Technical Provenance:**
   - Traceable catalog of indexed screenshots, HTTP headers, DOM selectors, Core Web Vitals.
   - Source Manifest with SHA-256 integrity hashes for each underlying stage artifact.
